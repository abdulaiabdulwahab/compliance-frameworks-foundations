# Azure Compliance Foundations Assessment

## Framework
NIST Cybersecurity Framework 2.0

## Control Area
ID.AM - Asset Management

## Technical Requirement
Azure resources must have a CostCenter tag.

## Evaluation Tool
Azure Policy

## Initial Finding
Storage account missing CostCenter tag.

## Corrective Action
Added CostCenter=CC100.

## Verification
Review before and after policy results.

## Limitation
Tag compliance supports asset accountability,
but does not prove full NIST CSF compliance.

## Final Result
